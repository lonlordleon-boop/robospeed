キャラ

カメラと再生位置は共通です。同じ角度・同じコマのまま切り替わるので、差だけが見えます。Spaceで順に切替。

どのキャラにも6つの動き（Idle / Run / Skip / Walk_Adult / Walk_Child / Wave）が入っています。

福笑い（2段目の「福笑い」に置く）

眉・目・口を部品ごとに動かします。スライダーを動かすと「福笑い」に切り替わります。 「直立不動」にして、1P と切り替えながら位置を合わせてください。

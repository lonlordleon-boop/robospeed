## 1.0.10（2026-10-24）

直したのは音まわりだけ。**遊びかたは変わっていない。**

### Android（versionCode 12）

```
・音をオフにしたとき、再生中の演出の音もすぐ止まるようにしました。これまでは、その演出が終わるまで鳴り続けていました。
```

59文字。（Play は 500文字まで）

### iPhone（Build 3）

```
・消音モードにしていても、ピュアカラーの演出の音だけが鳴ってしまう問題を直しました。
・音をオフにしたとき、再生中の演出の音もすぐ止まるようにしました。これまでは、その演出が終わるまで鳴り続けていました。
```

102文字。（App Store は 4000文字まで）

### なぜ2つで違うのか

| | Android | iPhone |
|---|---|---|
| 再生中の演出の音が止まらない | **あった** | **あった** |
| 消音モードで演出の音が鳴る | **無かった**（実機で確認） | **あった** |

iPhone の消音スイッチは効果音と BGM（Web Audio）には効くが、演出の動画（`<video>`）には
効かない。Android のマナーモードは**着信音だけ**を消す仕様で、メディア音は元から止めない。
**同じ文面を両方に貼ると、Android では直していないものを直したと書くことになる。**

詳しくは仕様書 7-7 の「iPhone の消音スイッチと、動画の音」。

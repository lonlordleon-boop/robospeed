## 0. 事前に確認した事実

| 調べたこと | 結果 |
|---|---|
| アプリが通信する先 | **自前のサーバー1つ**（ランキングAPI）＋ **Google AdMob** |
| Android の権限 | `INTERNET` **のみ** |
| 位置情報・カメラ・マイク・連絡先・写真 | **一切触っていない**（該当APIの呼び出しゼロ） |
| 端末内に保存するもの | 図鑑・自己ベスト・設定・名前・端末識別子（11個の localStorage） |
| サーバーへ送るもの | 名前 / 撃破数 / 平均・最速の組み立て / 生存時間 / 出撃回数 / 最高の役 / 最高連続攻撃 / 難易度 / アプリの版 / 端末識別子 |
| サーバーが追加で保存するもの | IPのハッシュ先頭16文字、登録日時 |

## 1. データ収集の有無

**「アプリはユーザーデータを収集または共有しますか？」→ はい**

理由：ランキング登録時に、名前・成績・端末識別子をサーバーへ送信している。

> **「いいえ」は選べない。** 端末内に閉じているデータだけなら「いいえ」だが、
> 本アプリはサーバーへ送っている。

---

## 2. 収集するデータの種類

### ✅ 個人情報 → 名前

| 項目 | 回答 |
|---|---|
| 収集するか | **はい** |
| 共有するか（第三者へ渡すか） | **いいえ** |
| 必須か任意か | **任意**（ランキングに登録しなければ送信されない） |
| 目的 | **アプリの機能**（ランキングの表示） |
| 一時的な処理のみか | いいえ（保存する） |
| ユーザーが削除を要求できるか | **はい**（問い合わせ先を記載） |

> 入力欄は自由入力で、本名を求めていない。ただし「名前」欄である以上、
> Play の分類上は **個人情報 → 名前** に当たる。**ここを「収集しない」にしない。**

### ✅ アプリのアクティビティ → アプリ内検索やその他の操作

| 項目 | 回答 |
|---|---|
| 収集するか | **はい** |
| 共有するか | **いいえ** |
| 必須か任意か | **任意** |
| 目的 | **アプリの機能**（順位の決定・表示） |

対象：撃破数、組み立ての平均・最速時間、生存時間、出撃回数、最高の役、
最高連続攻撃数、難易度、アプリのビルド番号。

### ✅ アプリの情報とパフォーマンス → その他のアプリ パフォーマンス データ

「アプリの版（ビルド番号）」をここに分類してもよい。
上の「アプリのアクティビティ」に含めて申告済みなら、二重に申告しない。

### ✅ デバイスまたはその他の ID → デバイスまたはその他の ID

| 項目 | 回答 |
|---|---|
| 収集するか | **はい** |
| 共有するか | **はい**（AdMob が広告IDを取得するため） |
| 必須か任意か | **必須**（広告のため） |
| 目的 | **広告またはマーケティング**（AdMob）＋ **アプリの機能**（1端末1記録の維持） |

> **2つの別物が同じ分類に入る。**
> ・本アプリが自作した16桁の乱数（サーバーへ送る。広告IDではない）
> ・AdMob が取得する広告ID（Google が取得。当方は受け取らない）
> **AdMob を入れている以上、この項目は「はい」以外にならない。**

### ❌ 収集しないもの（すべて「いいえ」）

位置情報 / メールアドレス / 電話番号 / 住所 / 支払い情報 /
連絡先 / 写真・動画 / 音声 / カレンダー / 健康 / メッセージ /
ファイルとドキュメント / ウェブ閲覧履歴 / 購入履歴

## 3. セキュリティに関する質問

| 質問 | 回答 | 根拠 |
|---|---|---|
| データは転送時に暗号化されますか | **はい** | 通信はすべて HTTPS。`allowMixedContent: false` |

## 4. よく間違える点（自分用の注意）

- **「収集していない」と答えたくなるが、答えてはいけない。**
  端末識別子も名前も、サーバーへ送っている時点で「収集」に当たる。
- **AdMob を入れたら「デバイスID／広告ID」は必ず「はい」。**
  自分で受け取っていなくても、アプリの中で取得されているため。
- **「共有」の意味は「第三者へ渡すか」。**
  ランキングが他の利用者に見えることは「共有」ではなく「アプリの機能」。
  ただし AdMob へのデータは Google という第三者へ渡るので「共有」に当たる。
- 広告を外す版を出すときは、**ここも直す。**

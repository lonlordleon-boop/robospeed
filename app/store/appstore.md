### 説明（4000文字まで）

```
カードを5枚そろえてロボットを組み立て、撃つ。それだけのゲームです。

■ 色が揃うほど強い

カードには5つの部位（頭・胸・腰・腕・脚）と、5社のメーカー色があります。
5枚そろえると機体が完成し、色の揃いかたで「役」が決まります。

  ワンペア → ツーペア → スリーカード → フルハウス
  → プリズム → フォーカード → ピュアカラー

上の役ほど威力が上がります。全部そろえたピュアカラーは、
ワンペアの11倍以上の一撃になります。

■ 急ぐか、狙うか

敵は倒すたびに速くなります。
じっくり色を揃えれば強い機体が組めますが、そのあいだに敵は組み終わります。
弱い役で早く撃つか、殴られるのを覚悟で強い役を待つか。
この判断が、そのまま撃破数の差になります。

攻撃を受けると機体の部位が壊れます。組みかけの機体ほど、崩されると痛い。

■ どこまで行けるか

1本の走りで何機倒せるかを競います。負けたら終わり。
オンラインランキングがあり、同じ撃破数なら組み立てが速いほうが上です。

難易度は3段階。敵が速くなる勢いだけが変わります。

  イージー … 敵の加速がゆるい
  ノーマル … これが基準
  ハード   … 敵がすぐ速くなる

■ 集める

出した機体は図鑑に記録されます。
7つの役 × 5社で、全35体。ピュアカラーは滅多に出ません。

■ 操作

タップだけです。フリックも長押しもありません。

---

・オンラインランキングは、記録を登録したときだけ通信します。
・広告は、走り終わった結果画面と一時停止中にのみ表示されます。
・アプリ内課金はありません。
・iPhone を消音モードにしていると、効果音とBGMは鳴りません。
```

## 3. App のプライバシー（App Store Connect の「App のプライバシー」）

### 3-1. 自前のぶん（ランキング）— 確定

コードで確かめた事実（`data-safety.md` と同じ）。**ランキングに登録したときだけ送る。**

| Apple の分類 | 送るもの | 目的 | ユーザーに関連付け | トラッキング |
|---|---|---|---|---|
| 連絡先情報 → **名前** | 12文字までの自由入力の名前 | App の機能 | **はい**（下の注） | いいえ |
| ユーザコンテンツ → **ゲームプレイのコンテンツ** | 撃破数・組み立ての時間・最高の役など | App の機能 | **はい** | いいえ |
| ID → **デバイス ID** | アプリが作った16桁の乱数（広告IDではない） | App の機能 | **はい** | いいえ |

> **関連付けは「はい」で答える（控えめに見るより、多めに見るほうが安全）。**
> 名前と成績は、同じ乱数の端末識別子に結び付けて保存しているため。
> Android の「名前」と同じく、**「収集しない」にはしない。**

### 3-2. AdMob のぶん — **Xcode のプライバシーレポートを見て決める**

Google の案内で分かっているのは、AdMob が集める**種類**だけ。

| Apple の分類 | 何か |
|---|---|
| 位置情報 → おおよその場所 | IP アドレスから推定 |
| ID → デバイス ID | 広告の識別子など |
| 使用状況データ → 製品の操作 | 起動時のタップ・動画の視聴など |
| 使用状況データ → 広告データ | 表示された広告 |
| 診断 → クラッシュデータ | SDK の不具合の調査 |
| 診断 → パフォーマンスデータ | 広告の表示などに使う |

**「ユーザーに関連付けられるか」「トラッキングに使うか」は、Google の案内に書かれていない。推測で答えない。**

Mac で Archive したあと、Xcode の Organizer でその Archive を右クリック →
**「Generate Privacy Report」** を押すと、AdMob（Google Mobile Ads）自身が申告している中身が PDF で出る。
**そこに書かれている種類・目的・関連付け・トラッキングを、そのまま写す。**

> 3-1 と 3-2 で同じ分類（デバイス ID）が出るときは、**両方の目的をまとめて1つに**申告する。

## 4. 画面写真

### 必要なもの

**iPhone の 6.9 インチ（1320×2868）** の画面写真。最低3枚、最大10枚。
これがあれば、ほかの大きさの iPhone には Apple が縮めて使う。

### 撮りかた

本人の iPhone（iPhone 16・1179×2556）で撮る。**大きさは Windows 側で 1320×2868 に直す**
（縦横の比がほぼ同じなので、引き伸ばして上下を数ピクセル足すだけ。絵は崩れない）。

Android と同じ並びで撮る（`listing.md` のスクリーンショットの表）：

| # | 撮る画面 | 見せたいもの |
|---|---|---|
| 1 | タイトル | 世界観と機体の絵 |
| 2 | 盤面（カードが並び、機体が組み上がりかけ） | **何をするゲームか**（いちばん大事） |
| 3 | 出撃の演出（役名が出ている瞬間） | 役が威力になること |
| 4 | ピュアカラーの演出 | いちばんの見せ場 |
| 5 | 結果画面 | 撃破数と記録 |
| 6 | ランキング | 競う相手がいること |
| 7 | 図鑑 | 集める要素 |
| 8 | 難易度の選択 | 3段階あること |

> **広告が写り込んでいる写真は使わない。** 結果画面は、広告が出る前か、上の広告のところを外して撮る。

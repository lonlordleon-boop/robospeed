## 4. デバイス ID の「トラッキング」— **A（許可を聞く画面を入れる）に決めた**（2026-10-20）

起動してすぐ、iPhone のときだけ許可を聞く。いま入っている AdMob の部品
（`@capacitor-community/admob` の `requestTrackingAuthorization`）で作るので、新しいパッケージは入れない。
**アップロード済みの Build 1 にはこの画面が入っていない。審査には、入れたあとの Build で出す。**

以下は決める前に書いた比べ：

AdMob は、デバイス ID を **トラッキングに使う**と申告している（広告の識別子 IDFA のこと）。
App Store Connect でも「トラッキングに使う」と答えることになる。

ところが、手順書 3-4 で **追跡の許可を聞く画面（ATT・`NSUserTrackingUsageDescription`）は入れていない。**
Apple は「トラッキングに使うと答えたのに、許可を聞く画面が無い」アプリを審査で止めることがある。

どちらにするかは **本人が決める**：

- **A. 許可を聞く画面を入れる** — `NSUserTrackingUsageDescription` を足し、起動時に「追跡を許可しますか」を出す作りを入れる。許可した人には本人に合わせた広告が出る
- **B. 入れない** — 許可を聞かないと IDFA は取れない（ゼロになる）ので、実際には追跡されない。ただし AdMob の申告は「する」のままなので、審査で聞かれたら説明が要る
